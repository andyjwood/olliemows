# 🌿 Ollie Mows the Lawn

A free, ad-free, kid-friendly mowing game that runs in your phone's browser and installs to your Home Screen like a normal app. Mow yards around a sunny cartoon town, trim the edges, and try not to hit the rocks.

## How to play

- **Drag** your finger (or mouse) to steer. Keep it far from Ollie to go fast. Lift it to stop.
- **Mow every patch of tall grass.** The little map shows what's left.
- **Don't mow the same spot twice.** Neat stripes earn more money.
- **Dodge rocks 🪨 and sticks 🪵.** Hitting them costs repair money.
- **Switch tools any time:**
  - 🌿 **Trimmer**: slow and skinny, reaches every edge
  - ⚙️ **Push mower**: a good all-rounder
  - 🚜 **Riding mower**: fast and wide, but turns slowly
- Tap **Done** when you're finished to get paid and earn up to 3 ⭐.

## The jobs

1. Mrs. Patel's Front Yard
2. Corner Lot
3. Backyard Pond
4. Maple School Field
5. Sunny Town Park
6. Big Meadow Farm

## Install on iPhone or iPad

1. Open the game's web address in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**.
3. Open it from the Home Screen icon. It works offline after the first load.

## Install on Android

Open it in Chrome, tap the **⋮** menu, then **Add to Home screen**.

## Privacy

No ads, no accounts, no tracking. Stars and earnings are saved only on your own device.

## Built with

Plain HTML, CSS and JavaScript (canvas). No frameworks and no downloads. Hosted free on GitHub Pages.
